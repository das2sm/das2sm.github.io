Real-time traffic sign detection on a $150 board

February–March 2026 · ACSI Laboratory, Feng Chia University
YOLOv4RK3588ONNXINT8 quantization

My first project at ACSI was to train a traffic-sign detector and get the whole pipeline running on an Orange Pi 5 Ultra, not just on a desktop GPU.

Training

I trained YOLOv4 on a 15-class traffic-sign dataset. The first run reached only 17.96% mAP@0.5. I checked the data pipeline, labels, anchors, and learning rate before narrowing the problem down to the optimizer setup. Switching from SGD with the existing weight decay to Adam changed the training behavior immediately. The next run passed 80% mAP@0.5, and after tuning I reached about 95%.

Deployment

After training, I exported the model through ONNX and converted it to RKNN so it could run on the RK3588 NPU in the Orange Pi. The deployed model used INT8 quantization.

PyTorch (.pth) → export →
ONNX (.onnx) → convert + quantize →
RKNN (.rknn, INT8) → deploy →
Orange Pi 5 Ultra (RK3588 NPU)

Once NPU inference was fast enough, CPU-side post-processing became noticeable. I vectorized the NumPy box decoding and non-maximum suppression code instead of leaving the hot path in Python loops. I also used all three NPU cores rather than serializing inference on one core.
