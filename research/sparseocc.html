Reproducing SparseOcc on nuScenes

March 2026 · ACSI Laboratory, Feng Chia University
3D perceptionDockerCUDAnuScenes

I wanted a working 3D occupancy baseline before moving into closed-loop planning. The model itself was not the hard part. Getting the published software stack to run on the hardware I had was.

Getting the environment to run

SparseOcc depends on an older OpenMMLab stack, including mmcv-full==1.6.0 and mmdet3d==1.0.0rc6, with CUDA 11.8 and PyTorch 2.0. The first GPU I tried was an RTX 5070 Ti. That card uses the newer Blackwell architecture, which CUDA 11.8 does not support.

I first tried keeping the original CUDA 11.8 setup in Docker. The extensions compiled, but inference failed because there was no compatible kernel for the GPU. I then tried moving the stack to CUDA 12.8, which supported the card but broke compatibility with the old mmcv/PyTorch combination. Building mmcv from source did not solve that mismatch either.

At that point I moved the project to an RTX 3090, where the original stack was supported. I packaged the working setup into Docker with the compiled CUDA extensions and environment checks so I could reproduce it cleanly on a fresh machine.

Result

MetricResult
RayIoU, ResNet-50 backbone on nuScenes0.368
Inference latency62.5 ms
Throughput16.0 FPS

The 0.368 RayIoU matched the published benchmark. I also exported bird's-eye-view semantic occupancy visualizations and used them to understand how the representation could feed into later planning work.

Why I did not use SparseOcc in the final study

The later closed-loop project used SparseDriveV2, and combining the two research codebases created another set of dependency conflicts. More importantly, the question I eventually wanted to test was cleaner with privileged occupancy from CARLA. Using simulator state removed perception noise and let me isolate whether occupancy-based trajectory reselection helped the planner at all.

So SparseOcc stayed as a separate reproduction and systems project rather than becoming the perception front end of the final intervention study.
